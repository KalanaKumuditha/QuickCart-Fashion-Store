# IT24104028 – Advanced Product Discovery & Showcase

## Assigned Functionalities
* Implement smart product search using keywords
* Provide filtering functionality
* Enable product sorting mechanisms
* Develop dynamic homepage showcase
* Highlight key product features

## Codebase Attribution & Methods

### `com.app.store.controller.StoreWebController.java`
* `index()` - Drives the dynamic homepage showcase by loading new arrivals and recently explored products into the model.
* `shop()` - Handles the core product discovery routing, consuming `keyword`, `category`, and `sort` query parameters.
* `productDetails()` - Fetches specific product profiles to highlight key product features on the detail page.

### `com.app.store.service.ProductService.java` & `com.app.store.service.impl.ProductServiceImpl.java`
* `getProductsWithFilterAndSort()` - Maps the smart search, filtering, and sorting mechanisms down to the repository layer.
* `getNewArrivals()` - Pulls the latest inventory for the dynamic homepage showcase.

### `com.app.store.repository.ProductRepository.java`
* `searchProducts()` - The explicit `@Query` driving the keyword matching algorithms.
* `findDistinctCategories()` - Parses the database for unique categories to populate the frontend filter dropdowns.

### Frontend & UI Templates
* `templates/index.html` - Houses the dynamic homepage showcase displaying new arrivals.
* `templates/shop.html` - The primary structural grid enabling smart search parameters, filtering interfaces, and product sorting mechanisms.
* `templates/product-details.html` - The dedicated view highlighting key product features individually.

## Workflow Explanation
The Advanced Product Discovery workflow begins at the `StoreWebController`. When a user visits the homepage (`/index`), the controller triggers `getNewArrivals()` to populate the dynamic showcase. When a user navigates to the `/shop` endpoint, the controller captures any applied search keywords, category filters, and sorting preferences from the URL parameters. These parameters are passed to `ProductService.getProductsWithFilterAndSort()`, which dynamically constructs a database query via the `ProductRepository` to isolate the exact inventory requested. The resulting catalog is passed to the Thymeleaf view layer, allowing users to discover and inspect key product features on the granular `/product/{id}` details page.
