# IT24101982 – Comparison and Market Intelligence

## Assigned Functionalities
* Best selling products analysis
* Monthly profit reporting
* Season demand prediction
* Feature highlighting (rating/ price)
* Performance optimized dynamic rendering
* Difference emphasize (manufacturing type/ icon)
* Comparison filtering

## Codebase Attribution & Methods

### `com.app.store.repository.OrderItemRepository.java`
* `findBestSellingProducts()` - A native SQL aggregation query executed against historical orders to compute the best selling products analysis.
* `findSeasonalDemand()` - A complex SQL mathematical prediction query mapping product purchase velocities over temporal limits for season demand prediction.

### `com.app.store.controller.AdminDashboardController.java`
* `dashboard()` - Ingests the `OrderItemRepository` analytics and compiles the monthly profit reporting natively inside the master Administrative layout.

### `com.app.store.controller.ComparisonController.java`
* `compare()` - Intercepts stateless URL arrays of product IDs (`/compare?ids=1,2`) for instantaneous grouping.
* Employs algorithmic logic inside the controller to discover the absolute lowest price out of the provided pool for automatic feature highlighting mapping.
* Operates heavily refined data-binding mechanisms to ensure performance optimized dynamic rendering before passing the block back to the HTML layout.

### `product/compare.html` & `product/list.html`
* Implements the UI difference emphasize (manufacturing type/ icon) utilizing Thymeleaf logic to explicitly demarcate rows where attributes (e.g., categories, sellers, dimensions) differ.
* Uses Javascript DOM manipulation for comparison filtering, enabling users to hide identical rows and "Show Only Differences" synchronously.

### Frontend & UI Templates
* `templates/admin/dashboard.html` - The administrative UI charts graphing the Best selling products analysis, monthly profit reporting, and seasonal demand predictions dynamically.
* `templates/product/compare.html` - The performance-optimized comparative grid. Implements robust HTML parsing to provide the "Difference emphasize" (detecting varying manufacturing traits, materials, or icons dynamically) alongside functional Comparison filtering toggles.
* `templates/shop.html` & `templates/product-details.html` - Includes the "Compare" checkboxes allowing the user to initiate the market intelligence routing.

## Workflow Explanation
This workflow empowers both the Administrative backend and the public Customer frontend with deep intelligence. On the Admin side, the `AdminDashboardController` mounts complex aggregation queries housed securely inside `OrderItemRepository`. These scripts scan thousands of historical transaction logs specifically searching for velocity spikes (`findBestSellingProducts`) and shifting calendar affinities (`findSeasonalDemand`), painting a high-level monthly profit report. For the end user, the intelligence manifests dynamically through the URL-stateless `ComparisonController`. When selecting multiple items, the controller pre-computes feature highlights like the "Lowest Price" before sending the JSON array to the `compare.html` layout. The frontend utilizes Javascript comparison filtering to emphasize structural differences (e.g., comparing a Cotton Shirt against a Polyester one), allowing the buyer to make an optimized, data-driven purchase decision.
