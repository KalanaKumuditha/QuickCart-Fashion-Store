# IT24103153 – Cart, Checkout & Chatbot

## Assigned Functionalities
* Cart grouping by product variants
* Delivery charge calculator
* Secure order placement
* OTP base secure authentication
* Payment gateway integration
* User registration, login, profile management
* Wishlist management
* Basic rule base chatbot for FAQ support

## Codebase Attribution & Methods

### `com.app.store.service.impl.CartServiceImpl.java`
* Grouping logic inside `getCart()` and `addToCart()` to ensure items are aggregated strictly by `ProductVariant` (Size/Color) rather than base products.
* `calculateDeliveryCharge()` - Executes the bounded delivery math logic (350 LKR < 12000 LKR < Free).

### `com.app.store.service.impl.OrderServiceImpl.java`
* `processOrder()` - Handles Secure Order Placement and houses the simulated Payment Gateway integration processing delay logic.

### `com.app.store.service.impl.OtpServiceImpl.java` & `com.app.store.service.EmailService.java`
* `generateAndSendOtp()` / `verifyOtp()` - Drives the secure OTP authentication logic.
* `sendOtpEmail()` inside `EmailService.java` - Dispatches the live SMTP verification token.

### `com.app.store.controller.AuthController.java` & `com.app.store.config.SecurityConfig.java`
* `register()`, `login()`, `verifyOtp()` - Controls the User Registration, Login, and Profile management handshakes.
* `SecurityConfig` drives all OAuth2 and local session management.

### `com.app.store.service.impl.OpenRouterChatService.java` & `com.app.store.controller.ChatbotController.java`
* Developed the AI-driven Chatbot (upgrading the basic rule-based requirement to an LLM) through `generateChatResponse()` which responds to user FAQ support requests dynamically.

### `com.app.store.service.impl.WishlistServiceImpl.java`
* `addToWishlist()`, `removeFromWishlist()`, `getUserWishlist()` - Manages the user's saved wishlist catalog.

### Frontend & UI Templates
* `templates/cart.html` - Drives the visual cart grouping logic and dynamic delivery charge calculator.
* `templates/checkout.html` - The secure order placement form representing the simulated payment gateway integration.
* `templates/login.html` & `templates/register.html` - Contains the OTP authentication input forms and user registration views.
* `templates/fragments/chatbot.html` - The floating interactive widget injecting the AI FAQ support capabilities.
* `templates/user/profile.html` - The base user profile management layout.
* `templates/user/wishlist.html` - The visual gallery for wishlist management.

## Workflow Explanation
This workflow handles the core conversion funnel and user security. When a user registers, `AuthController` creates their profile and delegates `OtpServiceImpl` and `EmailService` to dispatch a secure 2FA token to their inbox, keeping the account locked until verified. Once browsing, users add nested `ProductVariants` to their Cart, where `CartServiceImpl` intelligently groups identical sizes/colors and calculates conditional Delivery Charges. During checkout, `OrderServiceImpl` securely transfers the cart items to an official Invoice, simulating a secure Payment Gateway handshake before finalizing the transaction. Concurrently, users can interact with the floating Chatbot widget, which queries the `OpenRouterChatService` to answer store policy FAQs on demand.
